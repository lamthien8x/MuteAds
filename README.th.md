## ทำไมเราถึงสร้าง MuteAds

เช่นเดียวกับคุณ เราเหนื่อยหน่ายกับอินเทอร์เน็ตในปัจจุบัน: ป้ายแบนเนอร์กะพริบระรานตา สคริปต์ติดตามที่คอยบันทึกทุกการคลิก แบตเตอรี่ที่หมดเร็วอย่างน่าตกใจ และโปรแกรมบล็อกโฆษณาขนาดใหญ่ที่ทำให้เครื่องช้าหรือแอบขายข้อมูลผู้ใช้ เราสร้าง MuteAds ขึ้นมาด้วยเป้าหมายที่ตรงไปตรงมา: ตัดวงจรโฆษณาและตัวติดตามตั้งแต่ต้นตอ ด้วยการปฏิเสธการเชื่อมต่อไปยังโดเมนเหล่านั้นก่อนที่พวกมันจะปรากฏบนหน้าจอของคุณ

ไม่ต้องรูทเครื่อง (No root) ไม่ต้องสมัครสมาชิกหรือลงชื่อเข้าใช้ และที่สำคัญที่สุด: **ไม่มีประวัติการท่องเว็บของคุณแม้แต่ไบต์เดียวหลุดออกจากอุปกรณ์ของคุณ** การกรองทั้งหมดทำงานบนฮาร์ดแวร์ของคุณเองแบบ 100%

- **บล็อกระดับโดเมนที่เฉียบขาด**: ใช้งานได้ครอบคลุมทุกแอปในระบบ (Android, คอมพิวเตอร์) หรือภายในเว็บเบราว์เซอร์ของคุณโดยตรง (ส่วนขยาย)
- **ระดับการกรองที่ปรับแต่งได้ 5 ระดับ**: ตั้งแต่ระดับ "พื้นฐาน" (ปลอดภัยสูงสุด ไม่กระทบเว็บทำงานหรือเว็บธนาคาร) ไปจนถึง "สูงสุด" ระดับ 3 คือค่าเริ่มต้นที่ลงตัวที่สุดสำหรับทุกคน
- **บล็อกโฆษณา YouTube ในตัว**: รวมอยู่ในส่วนขยายเบราว์เซอร์แล้ว เพียงเปิดสวิตช์ก็รับชมวิดีโอได้อย่างต่อเนื่องโดยไม่มีโฆษณามาขัดจังหวะ
- **สวิตช์ควบคุมหลักเพียงปุ่มเดียว**: ชีวิตซับซ้อนพอแล้ว หากต้องการปิดการกรองชั่วคราวเพื่อทดสอบเว็บไซต์ คลิกเพียงครั้งเดียว ทุกอย่างจะกลับสู่สภาพปกติทันที
- **รองรับ DNS เข้ารหัสสมัยใหม่**: รองรับทั้ง DNS-over-HTTPS (DoH) และ DNS-over-TLS (DoT) บน Android และคอมพิวเตอร์ เพื่อป้องกันการสอดแนมจากผู้ให้บริการอินเทอร์เน็ต
- **ควบคุมกฎได้ด้วยตัวคุณเอง**: รองรับรายการอนุญาต (allowlist) รายการบล็อก (blocklist) และการแมป IP กำหนดเองพร้อมรองรับเครื่องหมายตัวแทน `*`

## ระดับการกรอง

| ระดับ | ชื่อโปรไฟล์ | สิ่งที่ถูกบล็อก |
| --- | --- | --- |
| 1 | พื้นฐาน (Basic) | เฉพาะเครือข่ายโฆษณาและตัวติดตามที่มีความสำคัญสูงสุดเท่านั้น ความเสี่ยงที่บล็อกผิดพลาดน้อยมาก |
| 2 | สมดุล (Balanced) | ครอบคลุมกว้างขึ้น รวมถึงแพลตฟอร์มการวิเคราะห์และเก็บสถิติทั่วไป |
| 3 | ครอบคลุม (Extended) | การปกป้องรอบด้านสำหรับการท่องเว็บในชีวิตประจำวัน **ค่าเริ่มต้นที่แนะนำ** |
| 4 | เข้มงวด (Strict) | การกรองเชิงรุก อาจส่งผลต่อวิดเจ็ตของบุคคลที่สามที่ฝังอยู่ในบางเว็บไซต์ |
| 5 | สูงสุด (Maximum) | ใช้รายการบล็อกทั้งหมด (ยกเว้นโซเชียลมีเดียหลัก) บางเว็บไซต์ที่มีความซับซ้อนอาจต้องเพิ่มข้อยกเว้น |

💡 **เคล็ดลับจากผู้พัฒนา:** หากเว็บไซต์ใดแสดงผลผิดปกติ เพียงลดระดับการกรองลงหนึ่งระดับ หรือปิดสวิตช์สักครู่

## การทำงาน (ไม่มีเวทมนตร์ใดๆ!)

ทุกครั้งที่แอปหรือหน้าเว็บต้องการโหลดข้อมูล จะต้องสอบถามหาที่อยู่ IP ของชื่อโดเมนนั้นก่อนเสมอ (ผ่านคำขอ DNS) MuteAds จะทำหน้าที่เป็นผู้เฝ้าประตูในเครื่องของคุณ:

- หากโดเมนนั้นอยู่ในรายชื่อเครือข่ายโฆษณาหรือตัวติดตาม MuteAds จะตอบกลับทันทีว่า: *"ไม่มีโดเมนนี้ (NXDOMAIN)"* การเชื่อมต่อจะไม่เกิดขึ้น ประหยัดทั้งอินเทอร์เน็ตและแบตเตอรี่
- หากเป็นเนื้อหาปกติที่คุณต้องการเปิด คำขอจะถูกส่งต่อไปยังเซิร์ฟเวอร์ DNS ปกติอย่างไร้รอยต่อ และหน้าเว็บจะโหลดด้วยความเร็วเต็มพิกัด

บน Android การทำงานนี้เกิดขึ้นผ่าน **Local Loopback VPN** ภายในเครื่องที่ไม่ส่งข้อมูลออกภายนอก บนคอมพิวเตอร์แอปจะทำหน้าที่เป็น DNS Resolver ประจำเครื่อง ในเบราว์เซอร์ส่วนขยายจะใช้ประโยชน์จากเอนจิน `declarativeNetRequest` ที่รวดเร็วเป็นพิเศษ

## ความเป็นส่วนตัวต้องมาก่อน: เราไม่ต้องการข้อมูลของคุณ

- **ไม่ต้องมีบัญชี ไม่ต้องล็อกอิน**: เราไม่มีแบบฟอร์มลงทะเบียนและไม่มีฐานข้อมูลผู้ใช้ส่วนกลาง
- **ทำงานในเครื่อง 100%**: การกรองทั้งหมดเกิดขึ้นในอุปกรณ์ของคุณ เราไม่มีเซิร์ฟเวอร์คอยสอดส่องเว็บไซต์ที่คุณเข้าชม
- **การอัปเดตที่โปร่งใส**: การเชื่อมต่อภายนอกอัตโนมัติเพียงอย่างเดียวของแอปคือการดาวน์โหลดรายการโดเมนที่อัปเดตสัปดาห์ละครั้งโดยประมาณ
- **ขอสิทธิ์เท่าที่จำเป็น**: ส่วนขยายขอเฉพาะสิทธิ์ที่จำเป็นอย่างยิ่งในการบล็อกคำขอ บันทึกการตั้งค่า ตัวจับเวลา และการทำงานกับ `youtube.com`

## ข้อควรรู้และคำแนะนำ

- **สำหรับผู้ใช้ Android:** อย่าลืมปิดฟังก์ชัน *Private DNS* ในการตั้งค่าเครือข่ายของโทรศัพท์ มิฉะนั้น Android จะข้ามตัวกรองในเครื่อง และอย่าลืมปิดการปรับแต่งแบตเตอรี่สำหรับแอป
- **โฆษณาจากโดเมนเดียวกัน:** การบล็อกด้วย DNS เพียงอย่างเดียวไม่สามารถตัดโฆษณาที่ส่งมาจากโดเมนเดียวกับเนื้อหาหลักได้ ด้วยเหตุนี้ส่วนขยายเบราว์เซอร์จึงมีโมดูลเฉพาะสำหรับ YouTube
- **การไล่จับระหว่างแมวกับหนูบน YouTube:** แพลตฟอร์มวิดีโอปรับปรุงสคริปต์โฆษณาอยู่เสมอ หากพบโฆษณาหลุดรอด โปรดอัปเดตส่วนขยายเป็นเวอร์ชันล่าสุด
