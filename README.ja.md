## 開発者が MuteAds を作った理由

私たちも皆さんと同じように、現代のインターネットにうんざりしていました。画面を覆い尽くす邪魔なバナー広告、行動を監視し続けるトラッキングスクリプト、無駄に消費されるバッテリー、そして動作を重くしたりデータを売り飛ばす肥大化した拡張機能……。だからこそ、MuteAds を開発しました。目的は極めてシンプルです。広告やトラッカーのドメインへの通信を根本から拒絶し、画面に届く前に消し去ること。

ルート権限は不要。アカウント登録も一切不要。そして最も大切なこと——**あなたの閲覧履歴や通信データは、1バイトたりとも端末の外へ送信されません**。すべてのフィルタリングは、あなた自身の手元の端末内で完結します。

- **ドメインレベルでの確実なブロック**: 端末上のすべてのアプリ（Android、デスクトップPC）またはブラウザ内（拡張機能）で強力に機能します。
- **柔軟な5段階フィルター**: 業務サイトを壊さない安全な「基本」レベルから、徹底的に遮断する「最大」レベルまで。デフォルトのレベル3が最もバランス良く快適です。
- **YouTube広告ブロック標準装備**: ブラウザ拡張機能に統合済み。スイッチを入れるだけで、動画の途中で鬱陶しい広告に邪魔されることがなくなります。
- **迷わないワンボタンスイッチ**: 人生はすでに十分複雑です。検証などで一時的にオフにしたい時も、ワンクリックで瞬時に元の状態へ戻せます。
- **暗号化DNS（DoH / DoT）対応**: Androidおよびデスクトップで DNS-over-HTTPS / DNS-over-TLS をサポート。プロバイダや公共Wi-Fiによる盗み見を防ぎます。
- **自分だけのルール設定**: 許可リスト（ホワイトリスト）、拒否リスト（ブラックリスト）、カスタムIP設定を完備。ワイルドカード `*` にも対応しています。

## フィルターレベル一覧

| レベル | 名称 | ブロック内容 |
| --- | --- | --- |
| 1 | 基本 (Basic) | 最優先の広告・トラッカードメインのみを遮断。誤検出のリスクが最も低い設定です。 |
| 2 | バランス (Balanced) | 一般的なアクセス解析やテレメトリドメインまでカバーを広げます。 |
| 3 | 拡張 (Extended) | 日常使いに最適な広域ブロック。**おすすめ（デフォルト設定）。** |
| 4 | 厳格 (Strict) | 極めて強力に遮断。外部埋め込みウィジェットなどに影響が出る場合があります。 |
| 5 | 最大 (Maximum) | 主要SNSを除く全リストを適用。一部の複雑なウェブサイトで表示崩れが起きる可能性があります。 |

💡 **開発者のワンポイント:** ページが正しく表示されない場合は、フィルターレベルを1つ下げるか、スイッチを一時的にオフにしてみてください。

## 仕組み（魔法ではありません！）

アプリやウェブページが何かを読み込もうとする際、まず最初に行われるのが「このドメインのIPアドレスを教えて」という問い合わせ（DNS問い合わせ）です。MuteAds は手元でその門番を務めます:

- 広告やトラッカーのドメインである場合、MuteAds は即座に*「存在しません（NXDOMAIN）」*と回答します。接続そのものが発生しないため、通信量とCPUバッテリーを大幅に節約できます。
- 通常の見たいコンテンツである場合、問い合わせは通常のアップストリームDNSサーバーへと転送され、普段通り一瞬で表示されます。

Android では通信を外部に送らない**完全ローカル完結のVPN**を利用し、PCではローカルDNSサーバーとして振る舞います。ブラウザ拡張では最新の高速API `declarativeNetRequest` を採用しています。

## プライバシー第一：あなたのデータには興味がありません

- **登録不要・ログイン不要**: メールアドレスや個人情報を求めるフォームは一切存在しません。
- **完全ローカル処理**: 外部に閲覧ログを収集・監視するようなサーバーは保有していません。
- **クリーンな通信**: アプリが自動で行う外部通信は、週に1回程度のブロックリスト更新取得のみです。
- **最小限の権限**: 拡張機能が要求する権限は、リクエスト遮断、設定保存、週次更新タイマー、および `youtube.com` へのアクセスのみです。

## 知っておくと役立つTips

- **Androidをお使いの方へ:** 本体のネットワーク設定にある *プライベートDNS (Private DNS)* を「オフ」にしてください（オンのままだとローカルフィルターが迂回されてしまいます）。またバッテリー最適化から除外してください。
- **ファーストパーティ広告について:** コンテンツと同じドメインから配信される広告は、DNSレベル単体ではブロックできません。そのため、ブラウザ拡張ではYouTube専用のブロック機構を別途搭載しています。
- **YouTubeとのいたちごっこ:** 動画プラットフォームは頻繁に配信仕様を変更します。万が一広告がすり抜けた場合は、拡張機能を最新版へアップデートしてください。
