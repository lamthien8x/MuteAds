## למה פיתחנו את MuteAds

בדיוק כמוכם, נמאס לנו מהאינטרנט של היום: באנרים מהבהבים בכל פינה, סקריפטים של מעקב שרושמים כל לחיצה, סוללה שנגמרת תוך שעות בודדות וחוסמי פרסומות כבדים שמאטים את המערכת או מוכרים מידע אישי. פיתחנו את MuteAds מתוך מטרה אחת פשוטה: לעצור פרסומות ומעקבים ישר מהשורש על ידי חסימת חיבורים לדומיינים שלהם לפני שהם בכלל מגיעים למסך.

ללא צורך ב-Root. ללא הרשמה או חשבונות. והכי חשוב: **אף בייט מהיסטוריית הגלישה שלכם לא עוזב את המכשיר**. כל הסינון מתבצע ב-100% באופן מקומי על החומרה שלכם.

- **חסימה אפקטיבית ברמת הדומיין**: עובד בכל האפליקציות במכשיר (אנדרואיד, מחשב) או ישירות בתוך הדפדפן (תוסף).
- **5 רמות סינון מדויקות**: מ-„בסיסי“ (בטוח לחלוטין, לא שובר אתרי עבודה) ועד „מקסימלי“. רמה 3 היא ברירת המחדל המאוזנת שלנו.
- **חסימת פרסומות YouTube מובנית**: משולבת ישירות בתוסף הדפדפן. הדליקו את המתג ותיהנו מסרטונים ללא פרסומות מציקות באמצע.
- **מתג הפעלה יחיד**: החיים כבר מספיק מסובכים. רוצים לכבות את הסינון לרגע כדי לבדוק משהו? לחיצה אחת והכל חוזר לקדמותו מיד.
- **DNS מוצפן מודרני**: תמיכה מלאה ב-DNS-over-HTTPS (DoH) וב-DNS-over-TLS (DoT) באנדרואיד ובמחשב להגנה מפני ספקי אינטרנט סקרנים.
- **שליטה מלאה בכללים**: רשימות מורשים (allowlist), רשימות חסימה (blocklist) והגדרות IP מותאמות אישית עם תמיכה בתווים כלליים `*`.

## רמות סינון

| רמה | פרופיל | מה נחסם |
| --- | --- | --- |
| 1 | בסיסי (Basic) | רק רשתות פרסום ומעקב בעלות עדיפות עליונה. כמעט ללא חסימות שגויות. |
| 2 | מאוזן (Balanced) | כיסוי רחב יותר הכולל שירותי ניתוח נתונים וטלמטריה נפוצים. |
| 3 | מורחב (Extended) | הגנה מקיפה לגלישה יומיומית. **מומלץ כברירת מחדל.** |
| 4 | קפדני (Strict) | סינון אגרסיבי. עשוי להשפיע לעיתים על רכיבים מוטמעים מאתרים חיצוניים. |
| 5 | מקסימלי (Maximum) | מחיל את כל רשימת החסימה (למעט רשתות חברתיות מרכזיות). אתרים מורכבים עשויים לדרוש החרגה. |

💡 **טיפ מהמפתחים:** אם אתר מסוים אינו נטען כראוי, פשוט הורידו את רמת הסינון בדרגה אחת או כבו את המתג לרגע.

## איך זה עובד (בלי שום קסמים!)

בכל פעם שאפליקציה או אתר רוצים להוריד תוכן, הם שואלים תחילה מהי כתובת ה-IP שמאחורי שם הדומיין (שאילתת DNS). כאן MuteAds משמש כשומר הסף המקומי שלכם:

- אם הדומיין שייך לרשת פרסום או מעקב, MuteAds עונה מיד: *„לא קיים (NXDOMAIN)“*. החיבור כלל אינו מתבצע, מה שחוסך חבילת גלישה וסוללה.
- אם מדובר בתוכן לגיטימי שביקשתם, השאילתה מועברת כרגיל לשרת ה-DNS הרגיל והאתר נפתח במלוא המהירות.

באנדרואיד זה מתבצע באמצעות **VPN מקומי פנימי** שאינו מעביר שום תעבורה החוצה. במחשב, האפליקציה פועלת כשרת DNS מקומי. בדפדפן, התוסף נעזר במנוע הרשמי המהיר `declarativeNetRequest`.

## פרטיות מעל הכל: המידע שלכם אינו מעניין אותנו

- **ללא חשבונות והתחברות**: אין לנו טופסי הרשמה ואין שום מאגר נתוני משתמשים.
- **100% במכשיר שלכם**: כל הסינון נעשה אך ורק מקומית. אין לנו שרתים שעוקבים אחר הרגלי הגלישה שלכם.
- **עדכונים שקופים**: הפעילות הרשתית האוטומטית היחידה של האפליקציה היא הורדת רשימות דומיינים מעודכנות בערך אחת לשבוע.
- **הרשאות מינימליות**: התוסף מבקש רק את ההרשאות הנחוצות בהחלט לחסימת בקשות, שמירת הגדרות, טיימר שבועי ותמיכה ב-`youtube.com`.

## דברים שחשוב לדעת

- **למשתמשי אנדרואיד:** הקפידו לכבות את אפשרות *Private DNS* בהגדרות הרשת של הטלפון, אחרת המערכת תעקוף את הסינון המקומי. בטלו גם את מיטוב הסוללה עבור האפליקציה.
- **פרסומות מאותו הדומיין:** סינון DNS טהור אינו יכול להסיר פרסומות המוגשות מאותו דומיין שבו נמצא התוכן הראשי. מסיבה זו התוסף כולל מודול ייעודי עבור YouTube.
- **משחק החתול והעכבר ב-YouTube:** פלטפורמות וידאו מעדכנות את סקריפטי הפרסום לעיתים קרובות. אם מופיעה פרסומת, ודאו שעדכנתם את התוסף לגרסה האחרוنة.
